# S3-3C：板块估值与资金流前端展示修复

阶段：S3-3 的最后一个子阶段。只改前端，后端契约、Provider、缓存逻辑全部未动。

## 1. 字段证据（来自本机真实缓存 `_data_cache.json` 的 496 条）

`/api/sector-valuation` 的 data 行，键集合 **恰好** 是：

```
['change', 'market_cap', 'name', 'pb', 'pe']
```

| 字段 | 真实情况 | 来源 |
|---|---|---|
| `pe` | 496/496 有值；负 PE 90 个；PE=0 0 个 | 东财 `f9`（Provider 已按 /100 处理） |
| `pb` | **496/496 全部 null** | 东财 `f23` 实测返回 `"-"`，Provider 转 None（不是 0） |
| `market_cap` | 496/496 有值，34.95 ~ 187,960.13（亿元） | 东财 `f20`（元），Provider `round(f20/1e8, 2)` |
| `change` | 496/496 | 东财 `f3` |

结论：**市值字段真实存在且可靠**，PB 在现有上游口径下全部缺失。
因此气泡图改为 PE × 市值，并把 PB 缺失明确写成"暂无数据"，不再画 PB=0 的假纵轴。

## 3. 前后对照

### 3.1 气泡图

改前：

```js
value: [s.pe, s.pb, s.market_cap, s.name]   // pb 全是 null → ECharts 画成 y=0
yAxis: { name: 'PB' }                        // 496 个点全压在 PB=0 一条线上
```

改后：

```js
const pts = sectorView.bubblePoints(sectors);   // PE null / 市值缺失都不画点，只计数
series = [正PE(红), 负PE(紫)]                    // x=PE, y=市值（亿元）
note  = 'PB：暂无数据（上游 496/496 返回 "-"），本图不使用 PB 轴；…'
```

### 3.2 PE 排行

改前：

```js
sectors.slice().sort((a, b) => b.pe - a.pe)     // null 参与减法 → NaN，负 PE 排进榜单
```

改后：

```js
const r = sectorView.peRank(sectors, 20);        // 只取 pe>0，升序；negative 单独一组
// 文案：共 496 个：正 PE 406（只用这些）、亏损 90（不代表低估值）、PE=0 0、缺失 0（--）
```

### 3.3 范围文案

`rangeText(meta, shown)` 只认元数据：

| 元数据 | 文案 |
|---|---|
| complete, total=496, shown=20 | `行业板块共 496 个，当前展示前 20 个。` |
| partial, rows=400, total=496 | `数据不完整：本次取得 400/496 个板块（缺 96 个），当前展示前 20 个。` |
| unknown, rows=496, total=null | `完整性未知：本次取得 496 个板块（上游总量未知），当前展示前 20 个。` |

`total` 未知时绝不出现"全部/共 N 个"；`partial` 时不出现"行业板块共"。
