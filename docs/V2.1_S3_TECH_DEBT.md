## 0. 分类原则

| 类别 | 定义 | 处理 |
|---|---|---|
| **A 实际缺陷** | 会产生错误数据、错误状态或不可见故障，可复现 | 进 S3，按阶段修 |
| **B 已知可接受限制** | 有真实约束（无源/无官方字段字典/生态限制），已明确标注 | 不修，写进 README/页面 |
| **C 未来优化** | 不改也正确，改了更好（性能/可维护性） | 不进 S3，进 S4+ 候选 |

**禁止**把 C 类塞进 S3；也禁止把 A 类以"以后再说"处理。

### TD-01　market_snapshot 不校验指数完整性，且按数组位置贴名称
- **严重度**：高（会把不完整/错配的大盘资金当完整数据展示）
- **位置**：`services/data/providers/eastmoney_flow.py::_normalize_snapshot`
- **证据**：请求 2 个指数、`diff` 只回 1 条 → `status=success`、`partial=False`、

  （实测输出见 `dist/evidence/S2_KNOWN_ISSUES.md`）
- **根因**：`for i, row in enumerate(diff)` 用位置索引 `indices[i]`；`status` 只按"非空"判定。
- **阶段**：S3-7（依赖契约 v2 的 `extra.partial/missing`，Q1）
- **验收**：8 条用例（2/1、2/2、2/3、乱序带 f12、无 f12、f12 错位、0 条、`total_incomplete` 不入完整缓存）

- **严重度**：低—中（误差绝对上限 50 万元；相对误差 = 50 万 ÷ 真实成交额）
- **位置**：`services/data/providers/tencent.py` `parse_quote()`：`round(turnover / 10000, 2)`
- **本质**：对外单位是亿元、保留两位小数 → **精度单位 0.01 亿元 = 100 万元**，四舍五入的绝对误差上限
  是 **50 万元**。它不是"只在小成交额才发生"，而是**任何价位都可能发生**；只是成交额越大，
  相对误差越小。必须与 S3-2 已删掉的"下限钳制"区分开 —— 那是**单向**把分母抬到至少 100 万元
  （<100 万元时系统性压低占比），舍入则是**双向** ±50 万元。

| 真实成交额 | 舍入后（对外） | 相对误差 | 方向 |
|---:|---:|---:|---|
| 49 万 | 0.00 亿 | 100%（分母为 0 → 占比 `null`） | 无数据 |
| 149 万 | 100 万 | 约 **+49%**（占比被放大） | 分母偏小 |
| 151 万 | 200 万 | 约 **-24.5%**（占比被少算） | 分母偏大 |
| 249 万 | 200 万 | 约 **+24.5%** | 分母偏小 |
| 251 万 | 300 万 | 约 **-16.3%** | 分母偏大 |
| 1 亿 | 1.00 亿 | ≤0.5% | — |
| 33.16 亿 | 33.16 亿 | ≤0.0015% | — |

- **影响范围（准确表述）**：所有成交额都有不超过 `50 万元 / 成交额` 的相对误差；
  只有当成交额达到 1 亿元量级时它才降到 0.5% 以下。**不能**说成"只影响 150 万元以下的标的"。
- **为什么不影响 S3-2 的结论**：测试用的真实样本 33.16 亿，误差 <0.002%；
  而"缺失/零/负数 → `null`"的判定不经过舍入（`None` 与 `0` 在舍入前就已区分）。
- **为什么本阶段不改**：两位小数是迁移前 `get_stock_quote` 的既有行为，18 字段迁移对照要求逐值一致；
  改精度会改变 `/api/stock-quote` 的对外数值，属于跨阶段契约变更。
- **建议修法（需单独授权，未实施）**：`parse_quote` 额外返回私有键（如 `_turnover_yi_raw`，未舍入），
  `get_stock_quote` 的 18 字段投影会自然过滤掉它 → API 契约零变化；
  `get_stock_real_money_flow` 用同一对象里的私有键做分母；需补"公网载荷无该键"断言。
- **阶段**：单独授权后再做，**不得**在 S3-3 里顺手扩大范围
- **状态**：已登记（S3-2 实测发现；S3-2 复审后修正范围描述）。**S3-2 已 CLOSED / PASS（2026-11-10）**，
  本债务按审查要求原样保留，关闭动作不包含任何精度修改
