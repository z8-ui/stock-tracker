## 4. 交付成果要点

**Provider / 数据完整性**
- 行业板块分页拉全（样本 496），`f12` 去重、`total` 一致性校验、`missing_pages` 可见。
- PB 上游全缺失保持 `null`（不补 0）；负 PE 保留真实数值（样本 90 个）。
- 部分数据不再被表述为"全部板块"。

**缓存 / 元数据**
- 业务数据仍是裸 list，JSON 键集合不变；旁路元数据与数据同文件持久化。
- 可信性 = schema + `data_hash` + `fetched_at` + `trace["version"]` 三重校验。
- 写盘失败 → `not_persisted` / `unknown`，不冒充持久化成功；后台 SWR 先落盘后发布。
- 10 个 `X-Data-*` Header 稳定输出完整性/新鲜度/来源。

**前端**
- 气泡图不再有虚假 PB=0；x=PE、y=市值，正/负分屏，PE=0 走独立类目轴（真实有限坐标）。
- PE 排行只用正 PE；亏损单列；PE=null 显示 `--` 且不入榜；PE=0 独立计数。
- Top N 与完整性文案只认元数据（complete/partial/unknown 三态各有措辞）。
- 网络失败可见、可重试、已有数据时保留旧图；热力图 15 秒自动刷新真实生效。
